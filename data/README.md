# Directorio de Datos (EMNIST Digits)

Coloca en este directorio los conjuntos de datos en formato CSV descargados de EMNIST:

- `emnist-digits-train.csv`
- `emnist-digits-test.csv`

> **Nota de Privacidad y Git:** Los archivos `.csv` están ignorados en el control de versiones (`.gitignore`) para evitar subir archivos pesados al repositorio. Puedes configurar rutas personalizadas mediante el archivo `.env`.
